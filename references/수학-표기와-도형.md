# 수학 표기와 도형

수식은 콘티의 글자 필드에 `$…$`로 쓴다. `plan`이 문법을 검사하고 `scaffold`가 MathML로 바꾼다. 아래 HTML은 **직접 원고에 쓸 때**의 참고다. SVG는 이미지 모델에 맡기지 않고 좌표를 계산한다.

## 1. 수식 문법

| 쓰기 | 뜻 |
| --- | --- |
| 숫자·영문자, `+ - = < > , . ( ) \| !` | 수·변수·연산자. 소문자는 기울임, 대문자는 정체, `-`는 `−` |
| `^{…}`, `_{…}` | 위·아래 첨자. 한 글자면 중괄호를 생략할 수 있다 |
| `\frac{분자}{분모}`, `\sqrt{…}`, `\sqrt[n]{…}` | 분수·제곱근·거듭제곱근 |
| `\times \div \pm \le \ge \ne \approx \cdot` | 연산·관계 기호 |
| `\angle \triangle \square \perp \parallel \equiv \sim` | 각·도형과 관계. 평행은 `⫽`, 닮음은 `∽` |
| `\pi \circ \therefore \because \cdots \quad` | 원주율·각도·따라서·왜냐하면·가운뎃점·공백 |
| `\overline{AB}`, `\overarc{AB}`, `\text{한글}` | 선분·호·정체 글자. 각도는 `60\circ` |
| `\val{식}` | `state`가 있는 조작 장에서만 쓰는 수식 속 조작 값 |

지원하지 않는 명령은 `plan` 오류다. `:`·`/` 같은 문자를 직접 수식에 넣는 대신 비는 `\text{:}`, 분수는 `\frac`를 쓴다. 단위·함수 이름을 묶을 때는 `\text{cm}`, `\text{sin}`처럼 쓴다. `$` 안의 공백은 출력 간격이 아니며 필요한 간격은 `\quad`로 준다. 글 속 변수는 `*x*`, 점 이름은 정체로 쓴다.

## 2. 수식 조각

각 조각은 바로 위 콘티 표기를 변환한 결과다. 원고에서 블록으로 보이게 하려면 `math`에 `display="block"`을 더하고 `.eq`로 감싼다. 여러 줄 정렬은 아래처럼 직접 원고에 쓰거나 장의 풀이 줄로 나눈다.

### 일차식

콘티: `$y=2x+1$`

```html
<math><mi>y</mi><mo>=</mo><mn>2</mn><mi>x</mi><mo>+</mo><mn>1</mn></math>
```

### 분수

콘티: `$\frac{7-3}{3-1}=2$`

```html
<math><mfrac><mrow><mn>7</mn><mo>−</mo><mn>3</mn></mrow><mrow><mn>3</mn><mo>−</mo><mn>1</mn></mrow></mfrac><mo>=</mo><mn>2</mn></math>
```

### 거듭제곱

콘티: `$a^3\times a^2=a^{3+2}=a^5$`

```html
<math><msup><mi>a</mi><mn>3</mn></msup><mo>×</mo><msup><mi>a</mi><mn>2</mn></msup><mo>=</mo><msup><mi>a</mi><mrow><mn>3</mn><mo>+</mo><mn>2</mn></mrow></msup><mo>=</mo><msup><mi>a</mi><mn>5</mn></msup></math>
```

### 근호

콘티: `$\sqrt{12}=\sqrt{2^2\times 3}=2\sqrt{3}$`

```html
<math><msqrt><mn>12</mn></msqrt><mo>=</mo><msqrt><mrow><msup><mn>2</mn><mn>2</mn></msup><mo>×</mo><mn>3</mn></mrow></msqrt><mo>=</mo><mn>2</mn><msqrt><mn>3</mn></msqrt></math>
```

### 부등식

콘티: `$2x-1\le 5,\quad x\le 3$`

```html
<math><mn>2</mn><mi>x</mi><mo>−</mo><mn>1</mn><mo>≤</mo><mn>5</mn><mo>,</mo><mspace width="1em"></mspace><mi>x</mi><mo>≤</mo><mn>3</mn></math>
```

### 좌표와 절댓값

콘티: `$P(1,3)$`

```html
<math><mi mathvariant="normal">P</mi><mrow><mo stretchy="false">(</mo><mrow><mn>1</mn><mo>,</mo><mn>3</mn></mrow><mo stretchy="false">)</mo></mrow></math>
```

콘티: `$|-3|=3$` (음수 부호는 숫자에 붙는다)

```html
<math><mrow><mo>|</mo><mrow><mo form="prefix" lspace="0em" rspace="0em">−</mo><mn>3</mn></mrow><mo>|</mo></mrow><mo>=</mo><mn>3</mn></math>
```

### 근의 공식

콘티: `$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$`

```html
<math><mi>x</mi><mo>=</mo><mfrac><mrow><mo form="prefix" lspace="0em" rspace="0em">−</mo><mi>b</mi><mo>±</mo><msqrt><mrow><msup><mi>b</mi><mn>2</mn></msup><mo>−</mo><mn>4</mn><mi>a</mi><mi>c</mi></mrow></msqrt></mrow><mrow><mn>2</mn><mi>a</mi></mrow></mfrac></math>
```

### 한글이 섞인 식

콘티: `$\text{기울기}=\frac{\text{y의 증가량}}{\text{x의 증가량}}$`

```html
<math><mtext>기울기</mtext><mo>=</mo><mfrac><mtext>y의 증가량</mtext><mtext>x의 증가량</mtext></mfrac></math>
```

`\text` 안은 통째로 본문 글꼴이다. 변수 `x`, `y`도 기울여야 하면 `\text{기울기}=\frac{y\text{의 증가량}}{x\text{의 증가량}}`처럼 분리한다.

### 비례식과 단위

콘티: `$2\text{:}3=x\text{:}6$`

```html
<math><mn>2</mn><mtext>:</mtext><mn>3</mn><mo>=</mo><mi>x</mi><mtext>:</mtext><mn>6</mn></math>
```

콘티: `$3\text{cm}+4\text{cm}=7\text{cm}$`

```html
<math><mn>3</mn><mtext>cm</mtext><mo>+</mo><mn>4</mn><mtext>cm</mtext><mo>=</mo><mn>7</mn><mtext>cm</mtext></math>
```

변환기는 `\text`를 `<mtext>`로 쓴다. 비의 쌍점 간격이나 단위와 숫자 사이의 좁은 간격을 더 다듬어야 할 때는 직접 원고의 MathML을 고친다.

### 순환소수와 삼각비

콘티: `$0.\overline{3}=\frac{1}{3}$`

```html
<math><mn>0.</mn><mrow class="seg"><mn>3</mn></mrow><mo>=</mo><mfrac><mn>1</mn><mn>3</mn></mfrac></math>
```

콘티: `$\text{sin}A=\frac{a}{c},\quad\text{tan}45\circ=1$`

```html
<math><mtext>sin</mtext><mi mathvariant="normal">A</mi><mo>=</mo><mfrac><mi>a</mi><mi>c</mi></mfrac><mo>,</mo><mspace width="1em"></mspace><mtext>tan</mtext><mn>45°</mn><mo>=</mo><mn>1</mn></math>
```

### 제곱근 계산

콘티: `$\sqrt{12}+\sqrt{27}=5\sqrt{3}$`

```html
<math><msqrt><mn>12</mn></msqrt><mo>+</mo><msqrt><mn>27</mn></msqrt><mo>=</mo><mn>5</mn><msqrt><mn>3</mn></msqrt></math>
```

### 선분과 평행, 삼각형과 닮음

콘티: `$\overline{AB}\parallel\overline{CD}$`

```html
<math><mrow class="seg"><mrow><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi></mrow></mrow><mo>⫽</mo><mrow class="seg"><mrow><mi mathvariant="normal">C</mi><mi mathvariant="normal">D</mi></mrow></mrow></math>
```

콘티: `$\triangle ABC\sim\triangle DEF$`

```html
<math><mi mathvariant="normal">△</mi><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi><mi mathvariant="normal">C</mi><mo>∽</mo><mi mathvariant="normal">△</mi><mi mathvariant="normal">D</mi><mi mathvariant="normal">E</mi><mi mathvariant="normal">F</mi></math>
```

콘티: `$\angle ABC=60\circ,\quad\triangle ABC\equiv\triangle DEF$`

```html
<math><mo>∠</mo><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi><mi mathvariant="normal">C</mi><mo>=</mo><mn>60°</mn><mo>,</mo><mspace width="1em"></mspace><mi mathvariant="normal">△</mi><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi><mi mathvariant="normal">C</mi><mo>≡</mo><mi mathvariant="normal">△</mi><mi mathvariant="normal">D</mi><mi mathvariant="normal">E</mi><mi mathvariant="normal">F</mi></math>
```

콘티: `$\overarc{AB},\quad\overline{AB}\perp\overline{CD},\quad\square ABCD$`

```html
<math><mover><mrow><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi></mrow><mo stretchy="true">⏜</mo></mover><mo>,</mo><mspace width="1em"></mspace><mrow class="seg"><mrow><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi></mrow></mrow><mo>⊥</mo><mrow class="seg"><mrow><mi mathvariant="normal">C</mi><mi mathvariant="normal">D</mi></mrow></mrow><mo>,</mo><mspace width="1em"></mspace><mi mathvariant="normal">□</mi><mi mathvariant="normal">A</mi><mi mathvariant="normal">B</mi><mi mathvariant="normal">C</mi><mi mathvariant="normal">D</mi></math>
```

선분 윗줄은 `class="seg"`로 그린다. `<mo>¯</mo>`는 Chrome에서 충분히 늘어나지 않는다. 반직선·직선 화살표, 순환소수의 점, 여러 줄 연립방정식은 변환기에 전용 문법이 없다. 필요한 경우 직접 MathML을 쓴다. 순환소수는 윗줄로도 나타낼 수 있다.

### 여러 줄 등식 — 직접 원고에서만 정렬

콘티의 두 풀이 줄: `$2x-2=x+3$`, `$x=5$`. 직접 작성할 때 등호를 맞춘 예다(변환기가 `mtable`을 만들지는 않는다).

```html
<math display="block"><mtable class="eqs">
  <mtr><mtd><mn>2</mn><mi>x</mi><mo>−</mo><mn>2</mn></mtd><mtd><mo>=</mo><mi>x</mi><mo>+</mo><mn>3</mn></mtd></mtr>
  <mtr><mtd><mi>x</mi></mtd><mtd><mo>=</mo><mn>5</mn></mtd></mtr>
</mtable></math>
```

1열은 오른쪽, 2열은 왼쪽 정렬이다. 수식은 칸보다 넓어도 꺾이지 않으므로 `math-overflow`가 나면 식을 나누거나 칸을 넓힌다.

### 연립방정식 — 직접 원고에서만 묶음

콘티의 두 식: `$x+y=5$`, `$2x-y=1$`. 두 식을 한 중괄호로 묶는 예다(각 식은 변환할 수 있지만 묶음 자체는 직접 쓴다).

```html
<math display="block"><mrow><mo>{</mo><mtable class="eqs">
  <mtr><mtd><mi>x</mi><mo>+</mo><mi>y</mi></mtd><mtd><mo>=</mo><mn>5</mn></mtd></mtr>
  <mtr><mtd><mn>2</mn><mi>x</mi><mo>−</mo><mi>y</mi></mtd><mtd><mo>=</mo><mn>1</mn></mtd></mtr>
</mtable></mrow></math>
```

## 3. SVG 공통 규칙

- `viewBox`와 `role="img"`, `aria-label`을 쓴다. `width`·`height`가 viewBox와 같아도 구도의 `.pic` 안에서는 칸에 맞춰 축소·확대된다. 축척과 실제 표시 크기를 함께 확인한다.
- 축척을 먼저 정하고 좌표를 계산한다. SVG의 y는 아래로 커진다. 점 이름은 정체, 변수는 기울임이다.
- CSS에 정의된 클래스만 쓴다. 색은 `currentColor`와 스티커 색을 따른다. 라벨은 선에서 떨어뜨린다.

| 클래스 | 쓰임 |
| --- | --- |
| `ln`, `thin`, `bold`, `dash`, `pt`, `pt open` | 기본 선 5, 가는 선 2.5, 굵은 선 8px, 점선, 점, 빈 점 |
| `soft`, `tint`, `solid`, `ang` | 하늘색·노란색 채움, 현재 색 채움, 각 표시 |
| `c-coral`, `c-yellow`, `c-mint`, `c-sky`, `c-violet` | SVG 요소의 현재 색 |
| `rod-edge` + `rod` | 같은 경로의 남색 42px 외곽선 위에 색 30px 막대를 겹친다 |
| `lb`, `lb it`, `lb ko`, `lb sm`, `lb start/end`, `lb bare` | 라벨, 변수, 한글, 작은 글자, 좌·우 맞춤, 테두리 없음. `tspan.it/rm/sup/sub`도 가능 |
| `g-grid`, `g-axis`, `g-tick`, `g-arrow`, `g-number`, `g-origin`, `g-name` | 엔진이 자동 생성하는 좌표평면 요소 |
| `path.curve`, `path.curve.sky/mint/violet/ink/dash`, `circle.gpt`, `circle.gpt.sky/mint/coral` | 함수 곡선과 점. 그래프에서는 `c-sky`가 아니라 이 변형 이름을 쓴다 |

## 4. 계산한 그림

다음 SVG는 각각 `show`나 `example`의 `draw`, 또는 `cards`의 각 항목의 `draw`에 넣는다. `show`의 넓은 그림 칸에서 아래가 넘치지 않도록 `viewBox`를 가로로 넉넉하게 잡았다. 다른 칸에서는 캡처를 보고 비율을 조정한다. 문자열 안의 큰따옴표는 JSON에서 `\"`로 이스케이프한다.

### 3 : 4 : 5 직각삼각형

A(100,400), B(500,400), C(100,100), 1단위 = 100 SVG 단위. AB = 400, AC = 300, BC = 500. A의 두 변은 수평·수직이므로 직각이다.

```html
<svg width="1600" height="500" viewBox="-480 0 1600 500" role="img" aria-label="각 A가 직각이고 변의 길이가 3, 4, 5인 삼각형 ABC">
  <path class="ln soft" d="M100 400L500 400L100 100Z"/>
  <path class="ln thin" d="M100 370H130V400"/>
  <circle class="pt" cx="100" cy="400" r="7"/><circle class="pt" cx="500" cy="400" r="7"/><circle class="pt" cx="100" cy="100" r="7"/>
  <text class="lb" x="65" y="420">A</text><text class="lb" x="530" y="420">B</text><text class="lb" x="65" y="90">C</text>
  <text class="lb" x="65" y="250">3</text><text class="lb" x="300" y="440">4</text><text class="lb" x="325" y="220">5</text>
</svg>
```

### 원과 60° 호

O(240,240), 반지름 180. A(420,240), B(330,84.1)은 각각 오른쪽과 60° 방향이다. OB의 길이는 약 180이다.

```html
<svg width="1600" height="480" viewBox="-560 0 1600 480" role="img" aria-label="중심 O, 반지름 OA와 OB, 중심각 60도인 호 AB">
  <circle class="ln" cx="240" cy="240" r="180"/>
  <path class="ln bold c-coral" d="M420 240A180 180 0 0 0 330 84.1"/>
  <path class="ln thin" d="M240 240H420M240 240L330 84.1"/>
  <path class="ang" d="M240 240L290 240A50 50 0 0 0 265 196.7Z"/>
  <circle class="pt" cx="240" cy="240" r="7"/><circle class="pt" cx="420" cy="240" r="7"/><circle class="pt" cx="330" cy="84.1" r="7"/>
  <text class="lb" x="210" y="260">O</text><text class="lb" x="452" y="250">A</text><text class="lb" x="350" y="48">B</text><text class="lb sm" x="310" y="205">60°</text>
</svg>
```

### 막대의 길이 비

축척 1 = 100, 세 막대의 중심선 길이는 300·400·500이므로 3 : 4 : 5다. 외곽선과 색 선에 같은 좌표를 쓴다.

```html
<svg width="1600" height="360" viewBox="-480 0 1600 360" role="img" aria-label="길이의 비가 3 대 4 대 5인 세 막대">
  <path class="rod-edge" d="M80 80H380M80 180H480M80 280H580"/>
  <path class="rod c-coral" d="M80 80H380"/><path class="rod c-sky" d="M80 180H480"/><path class="rod c-yellow" d="M80 280H580"/>
  <text class="lb" x="425" y="80">3</text><text class="lb" x="525" y="180">4</text><text class="lb" x="620" y="280">5</text>
</svg>
```

### 좌표평면과 일차함수

엔진이 모눈·축·눈금·원점과 축 이름을 그린다. `data-fn`은 함수식, `data-pt`는 수학 좌표다. `box`를 생략하면 두 축의 한 칸 길이를 같게 하여 가운데에 놓는다(`"equal": false`로 끔). 눈금 숫자·축 이름·원점은 캔버스 기준 기본 32px 이상이다. `font`를 주면 그 SVG 단위 값을 쓰므로 표시 배율까지 확인한다. `ticks`를 생략하고 칸이 좁으면 글자를 줄이지 않고 숫자만 일부 건너뛰며, 모눈은 그대로다. `ticks`를 직접 주면 그 간격을 따른다. 점마다 SVG 좌표를 손으로 적지 않는다.

```html
<svg width="1600" height="600" viewBox="-480 0 1600 600" data-graph='{"x":[-5,5],"y":[-5,5],"box":[80,60,480,480],"font":32}' role="img" aria-label="일차함수 y는 2x 더하기 1과 점 1, 3">
  <path class="curve" data-fn="2*x+1"/>
  <circle class="gpt" r="14" data-pt="1, 3"/>
</svg>
```

검산: `2×1+1=3`. 그림 영역에서 원점은 (320,300), 점 (1,3)은 (368,156)이다. 그래프는 y = −5와 5에서 각각 x = −3과 2이므로 경계의 대략 (176,540), (416,60)을 지난다. 정적 그래프도 엔진이 장에 들어올 때 그린다. 스크립트가 빠지는 공유 화면에는 별도 정적 그림이 필요하다.

콘티에서 `show`의 `draw`에 넣는 예(위 그래프와 같은 식·점):

```json
{"id":"line","layout":"show","title":"그래프의 점","purpose":"직선이 지나는 점의 좌표를 확인한다","focus":"점 P의 위치","draw":"<svg viewBox=\"-480 0 1600 600\" data-graph='{\"x\":[-5,5],\"y\":[-5,5],\"box\":[80,60,480,480],\"font\":32}' role=\"img\" aria-label=\"일차함수와 점 1, 3\"><path class=\"curve\" data-fn=\"2*x+1\"/><circle class=\"gpt\" r=\"14\" data-pt=\"1, 3\"/></svg>"}
```

`cards`에서는 `cards` 배열의 각 객체에 `"draw"`, `example`에서는 장의 `"draw"`에 같은 SVG 문자열을 넣는다. 곡선에는 `data-fn="x*x"` 등 JS 식을 쓰고, 점을 찍을 때 식에 대입해 검산한다. 여러 곡선은 색뿐 아니라 이름표로 구별한다.

## 5. 확인할 것

- 변의 길이·수직·평행·각도와 그래프 위의 점을 수로 계산한다. 눈대중으로 맞추지 않는다.
- 수식의 대문자 점 이름은 정체, 변수는 기울임이다. 직접 쓰는 MathML에서는 `<mi mathvariant="normal">A</mi>`를 확인한다.
- SVG의 분수·근호 이름표는 그림 밖 HTML의 MathML로 둔다. 라벨은 축·선·다른 글자와 겹치지 않게 한다.
- `check --shots`가 만든 장별 화면을 열어 그림의 비율·잘림·겹침을 본다. 자동 검사는 수학의 정오를 대신 판단하지 않는다.
