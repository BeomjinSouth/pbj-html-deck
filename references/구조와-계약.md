# 구조와 계약

스킬을 유지보수하거나 위젯·엔진의 정확한 약속이 필요할 때 읽는다. 콘티 작성은 [콘티 쓰기](콘티-쓰기.md), 모양은 [디자인 가이드](../Design.md), 수식과 SVG는 [수학 표기와 도형](수학-표기와-도형.md)을 본다.

## 1. 원칙

- 콘티가 장의 목적·구도·내용의 원본이다. 등록된 구도로 뼈대를 만들고 시안에 맞춰 원고를 다듬는다.
- 엔진·부품은 공용이다. `build`가 원고·그림·글꼴을 편집 가능한 HTML 한 파일로 묶는다. 저장 파일은 `unpack`으로 다시 풀 수 있다.
- 1920×1080 캔버스와 첫 장의 기본 배치는 스크립트 없이도 보인다. 자동 좌표평면과 위젯은 엔진이 그리거나 동작시킨다.
- 산출물은 외부 요청 없이 `file://`에서 연다. 검사·대조는 실제 브라우저와 캡처로 확인한다. 애니메이션은 항상 재생한다.

## 3. 문서·등록부·틀

### 원고와 결과

원고는 `<html lang="ko" data-palette="sunny">` 안에 `<section class="slide" data-id="…" data-layout="…">`를 `body`의 직계 자식으로 둔다. `data-id`와 `data-layout`은 콘티와 짝짓는 표다. 그림은 원고 기준 상대 경로다. 덱 전용 `<style>`·`<script>`는 필요할 때만 쓴다.

`build` 결과의 장은 `.viewer > #deck > section.slide[data-slide]` 아래에 있다. `data-deck="basefont|kit|engine"`은 공용 사본으로 다시 묶을 때 교체하고, `data-deck="fonts"`와 덱 전용 블록은 보존한다. `data-deck-page`로 정적 쪽 번호를 그린다. `deck-saved` 표시가 있는 다른 결과를 덮어쓰려면 `--force`가 필요하다. `<html data-lock="view">`는 학생용으로 편집을 잠근다.

교실 공유의 약속은 장 중첩 금지, `--bar`, `data-waiting`, 평평한 CSS(`@import`·`@scope`·중첩 선택자 금지), `data:`·`#조각` 외의 CSS URL 금지, 장 안에 `form` 없음이다. 동적 그래프의 자동 요소는 실행할 때 만들어지므로 스크립트 없는 공유 화면에도 필요하면 원고에 별도 정적 그림을 준비한다.

### 등록부

| 키·형식 | 뜻 |
| --- | --- |
| `name`, `use`, `group`, `visual`, `interaction`, `mockup` | 이름·쓰임·수업 단계·그림 필수 여부·상호작용·시안 설명 |
| `buddy` | `say`는 마스코트와 말풍선, `pose`는 그림만, `null`은 자리 없음. 자리 없는 필드는 `plan` 오류 |
| `text`, `asset`, `raw`, `json` | 표시 변환할 글·에셋 id·날것 문자열·속성용 객체/배열. `raw`에 `visual:true`면 직접 그린 그림으로 센다 |
| `list`, `object`, `bool`, `number`, `choice` | `of`의 항목·객체, 참/거짓, 수, `options`의 값. 목록과 수는 `min`·`max` 사용 |
| `max:[글자,줄]` | 한글 1, 공백 0.5, 영문·숫자는 글자별 폭으로 센다. 수식은 분수·첨자와 연산자 간격을 반영한 표시 폭으로 센다. 자동으로 접히는 줄까지 전체 줄 수를 검사하며, 수식 하나가 한 줄 한도보다 길면 여러 줄 칸에서도 오류다 |

`layouts [키,…]`로 등록부와 필드·한도·예시를 본다. 콘티의 `**강조**`, `*변수*`, `$수식$`, `[[답]]`은 표시로 바뀐다. `state`가 있는 장의 `{식}`·`{식:자리}`와 수식의 `\\val{식}`은 처음 값을 미리 적고 실행 중 갱신한다. 미리 계산하지 못하는 식은 `…`을 쓰고 브라우저에서 채운다.

### 틀 문법

| 쓰기 | 결과 |
| --- | --- |
| `{{name}}` / `{{{name}}}` | 표시 변환·이스케이프 / 날것. 속성 안의 일반 값은 평문으로 이스케이프한다 |
| `{{#name}}…{{/name}}` / `{{^name}}…{{/name}}` | 목록 반복·객체/참 한 번 / 없거나 빈 값일 때 |
| `{{.}}`, `{{@i}}`, `{{@n}}`, `{{@count}}`, `{{@first}}`, `{{@last}}`, `{{@rank}}` | 현재 항목, 0부터·1부터 순서, 개수, 처음·마지막, 섞기 전 순서 |
| `{{#name\|shuffle}}` | 장 id를 씨앗으로 결정적으로 섞음 |
| `{{asset:FIELD}}`, `{{asset:FIELD\|클래스}}` | `그림/ID.png`의 `img.asset`과 `data-asset`·`alt`. 값이 없으면 비움 |
| `{{step}}`, `{{step:same}}` | 장 안에서 새 단계 번호 / 직전 번호. `reveal:all`이면 둘 다 비움 |
| `{{! 주석 }}` | 출력하지 않음 |

이름은 안쪽 항목 → 장 → `meta`·`deck` 이름으로 접근하는 콘티 최상위 순이다. 장에 없는 이름이 최상위의 같은 필드로 새지 않는다. `scaffold`는 `_no`, `_tone`, `_len.<필드>`, `_mmss.<필드>`를 계산하고 장에 `data-id`·`data-layout`이 없으면 붙인다. 견주기(`compare`)의 VS는 둘째 카드와 함께, 정리(`summary`)의 말풍선과 다음 시간 띠는 마지막 정리 줄과 함께 나타난다. 정리의 대사가 여러 개면 다음을 누를 때마다 바뀌고 `reveal: "all"`이면 처음부터 내용과 첫 대사만 보인다. 이미 있는 장은 보존하며 `--force`일 때 선택한 장을 다시 쓴다.

## 4. 캔버스와 배율

- `#deck`은 16:9 컨테이너, `.slide`는 1920×1080px이며 `scale(tan(atan2(100cqw,1920px)))`으로 줄인다. 장 안 좌표는 캔버스 px다. 제목 자동 맞춤의 `cqw`는 부품 내부의 예외다.
- 스크립트 전에는 첫 장만 보인다. 숨긴 장에 SVG 정의가 있으면 Chrome 참조를 위해 레이아웃에 남기되 보이거나 눌리지 않게 한다.
- 모아보기는 장의 복제본을 같은 비율의 컨테이너에 넣는다. 인쇄는 1920×1080으로 전체 장과 대기 단계를 펼친다.

## 5. 장 안에서 쓰는 속성

| 속성 | 뜻 |
| --- | --- |
| `data-slide`, `data-deck-page` | `build`가 붙이는 장과 쪽 번호 |
| `data-title`, `data-name` | 모아보기·검사에 쓸 장 이름, 편집기 경로 이름 |
| `data-step="N"`, `data-until="M"` | N에 나타나고 M에 사라짐. M도 단계 수에 포함. 엔진이 `data-waiting`·`data-gone`과 방금 나타난 `is-now`를 붙인다 |
| `data-in="pop\|rise\|drop\|left\|right\|zoom\|fade\|draw"` | 단계 등장 효과. SVG의 `draw`를 제외하면 모양은 부품 CSS가 정한다 |
| `data-jump="N"`, `data-zoom` | 해당 단계로 이동 / 복제 화면 확대. 현재 단계의 점프에 `is-now` |
| `data-keep` | 위젯·탐구 뿌리나 그 조상에 두면 장을 떠나도 상태 유지. 명시적 초기화·저장에는 유지하지 않음 |
| `data-skip`, `data-lock`, `data-bleed`, `data-over`, `data-roomy` | 순차 발표 건너뜀, 편집 선택 제외, 의도된 캔버스 밖, 의도된 그림 위 글자, 뜻한 여백의 `empty-space` 검사 제외 |
| `data-runtime` | 실행 중 생성한 요소. 저장 때 제거 |
| `data-deck-e`, `data-deck-o`, `data-deck-src` | 엔진·도구의 편집 상태, 원래 style, 그림 원래 경로. 지우지 않는다 |

`is-*`·`data-mood`·`data-waiting`·`data-gone`은 엔진 상태이므로 작성자가 원고에 쓰지 않는다. 저장은 장 안의 실행 상태를 정리한다.

## 6. 엔진 (`assets/engine/`)

`build`는 CSS를 파일 이름순으로, JS는 `deck.js` → `widgets.js` → `lab.js` → `pen.js` → 나머지(`lint.js` 등) 순으로 합친다. `window.deck`은 즉시 생기고 초기화는 DOM 준비 뒤에 한다.

### 보기·편집·저장

보기 막대는 이전·쪽·다음·모아보기·펜·처음으로·편집·발표다. 편집 패널은 전체 크기·글꼴·색, 요소 선택·이동·크기·글자, 장 추가·복제·순서·삭제, 저장·학생용 저장·인쇄를 제공한다. `→`·`Space`는 다음 단계, `←`는 이전, `F` 발표, `G` 모아보기, `E` 편집, `D` 밝게/어둡게, `R` 초기화, `P` 판서, `Ctrl+S` 저장이다. 편집 모드의 위젯은 `Ctrl`+누르기로 동작한다.

| 공개 API | 뜻 |
| --- | --- |
| `deck.ready`, `count`, `slides`, `page`, `step`, `mode`, `dirty`, `selection` | 준비 Promise와 현재 상태. `page`는 0부터 |
| `go(page, step)`, `next()`, `prev()`, `setMode(mode)`, `overview(open, {columns})` | 이동·모드·모아보기. `step`에 `all` 가능 |
| `undo()`, `redo()`, `title(page?)`, `serialize()`, `reset(page?)` | 편집 되돌림·이름·저장 문자열·상태 초기화 |
| `on(type, fn)` | `slidechange`, `modechange`, `change`, `save`, `answer` 구독. 구독 해제 함수를 돌려준다 |
| `audit(page?)`, `selftest(page?, {hold:false})` | 구조·화면 검사 / 실제 이벤트를 보내는 동작 시험. `hold:true`는 마지막 상태를 `reset()`까지 남긴다 |
| `lab(rootOrSelector, render)` | 조작 탐구의 덱 전용 그리기. `deck.lab.state(root)`, `deck.lab.set(root, patch)`도 제공 |

### 확장 연결

`deck.ext(name, hooks)`의 훅은 `init(api)`, `enter(slide,page)`, `leave(slide,page)`, `reset(slide)`, `mode(mode,prev)`, `key(event)`, `validate(slide)`, `selftest(slide)`다. 키 훅이 `true`를 돌려주면 전역 단축키보다 먼저 처리된다. 검사 훅의 문제는 `audit`·`selftest`에 합친다.

확장에 주는 `api`: `active()` 보기·발표 여부, `scale()` 배율, `point(event)` 캔버스 좌표, `layer(slide)` 저장에서 빠지는 런타임 층, `keep(el,attr?)`·`restore(root)` 원래 값 복원, `result(el,{type,correct,solved})` 답 이벤트·마스코트·효과, `fx(el,'burst'|'shake')`, `toast(text)`, `interactive(selector)` 편집 중 Ctrl 조작 대상 등록.

### 위젯

| 위젯과 속성 | 동작·상태 |
| --- | --- |
| `[data-quiz]` + `[data-opt]`·`[data-correct]`·`[data-explain]` | 기본은 다시 고르기, `once`는 한 번, `multi`는 여러 보기와 `[data-check]`. `is-picked`, `is-correct`, `is-wrong`, `is-dim`, `is-solved`, `is-missed`, 풀이 `is-open` |
| `[data-flip]`, `[data-peek]`, `[data-toggle]` | 앞뒤 면 `is-flipped`, 가리개 `is-open`, 켜기 `is-on`. `data-group`의 토글은 장 안에서 하나만 켠다 |
| `[data-tabs]` + `[data-tab="k"]`·`[data-pane="k"]`·`data-start` | 단추 `is-on`, 다른 칸 `is-off`. `hidden`은 건드리지 않음 |
| `[data-sort]` + `[data-chip data-to="k"]`·`[data-bin="k"]`·`[data-pool]` | 끌거나 칩과 칸을 차례로 누른다. `data-max`로 칸 용량 제한. `data-sort="order"`는 `[data-lane]`과 `data-rank` 사용 |
| 끌어 놓기 상태 | `is-picked`, `is-drag`, `is-over`, `is-placed`, `is-correct`, `is-wrong`, `is-solved`. `[data-check]`가 없으면 놓는 즉시 채점하고 오답은 대기 칸으로 돌려보낸다. 칸은 `elementsFromPoint`로 찾는다 |
| `input[data-answer="7\|7cm"]`·`data-tol`, `[data-inputs]`, `[data-check]` | 대안 답·수치 오차·묶음 채점. Enter도 가능. 입력 `is-correct`/`is-wrong`, 묶음 `is-solved`. `textarea[data-note]`는 채점하지 않음 |
| `[data-timer="초"]`, `[data-pick="1-28"]`, `[data-count]` | 타이머 `--timer-left`, `is-running`·`is-done`; 뽑기는 `[data-pick-out]`, `is-rolling`, 한 바퀴 동안 중복 없음; 세기는 `[data-count-out]`, 누르면 +1, Shift+누르면 −1 |
| `[data-buddy]` 안 `[data-when="idle\|correct\|wrong\|done"]` | 결과에 따라 뿌리 `data-mood`를 바꾼다. `.when-idle`·`.when-yes`·`.when-no` 그림은 부품이 전환 |

장을 떠나면 위젯을 초기화한다(`data-keep` 제외). 편집 진입·저장·`R`에서는 초기화한다. 포인터로 누른 단추는 초점을 놓는다.

### 조작 탐구와 판서

`[data-lab='{"a":1}']`의 상태를 `[data-var]` 입력·`data-set="a=2"`·`data-add="a:0.5"`로 바꾼다. `data-show`·`data-fix`, `data-if`(`is-off`), `data-bind="속성: 식; --변수: 식; text: 식"`이 표시를 바꾼다. 식은 JS 식과 `Math` 이름·상태 이름이다.

`svg[data-graph]`는 x·y 범위와 선택적 `box`, `equal`, `grid`, `ticks`, `labels`, `origin`, `font`로 모눈·축·눈금·원점을 그린다. `box`가 없으면 두 축의 한 칸을 같은 길이로 가운데에 맞추며 `"equal": false`로 끌 수 있다. 눈금 숫자·축 이름·원점은 캔버스 기준 기본 32px 이상이고, `font`를 지정하면 그 SVG 단위 값을 쓴다(실제 크기는 SVG 배율을 따른다). `ticks`를 생략하고 숫자 간격이 좁으면 글자를 줄이지 않고 일부 숫자만 건너뛰며 모눈은 그대로 둔다. `ticks`를 지정하면 그 간격을 따른다. `path[data-fn]`은 200점으로 그리고 `data-domain="작은수..큰수"`로 범위를 좁힌다. `[data-pt="x식,y식"]`은 좌표에 놓는다. `[data-drag="x변수,y변수"]`에 `data-snap`, `data-range`, `data-axis`를 더할 수 있다. 정적 그래프도 `data-lab` 없이 `data-graph`만으로 열린 장에서 그린다. 초기 조작 그림은 원고에 마련한다.

판서는 `P`: 검정·파랑·빨강 펜, 형광펜, 획 지우개, 모두 지우기. 획은 장별 캔버스 좌표로 메모리에만 남고 저장 파일에는 들어가지 않는다. 켜진 동안 포인터는 판서에 쓰고 키보드 장 넘김은 유지한다.

`audit` 결과는 장 번호(1부터), `level`, `code`, `message`, `target`, `rect`다. 모든 단계를 펼쳐 측정한다.

| 코드 | 수준 | 조건 |
| --- | --- | --- |
| `overflow-canvas`, `text-clipped`, `math-overflow` | 오류/경고 | 캔버스 4px 초과(글자는 오류), 글자 잘림, 수식 넘침 |
| `text-overlap`, `small-text`, `low-contrast` | 경고/오류 | 글자 겹침 20% 초과, 26px 미만(20px 미만 오류), 단색 대비 3:1 미만 |
| `image-broken`, `empty-slide`, `no-title` | 오류/경고 | 깨진 그림, 빈 장, 제목 없음 |
| `external-resource`, `plain-math` | 경고 | 외부 자원, 날것 수식 |
| `widget-invalid`, `widget-broken`, `plan-mismatch`, `console-error` | 오류 | 위젯 구조, 자체 시험 실패, 콘티·원고 불일치, 브라우저 오류 |
| `placeholder-left`, `image-distorted`, `slide-is-image` | 오류 | 빠진 에셋, 원본 비율에서 3% 초과 왜곡, 불투명 단일 그림이 대부분인 장 |
| `image-upscaled`, `text-heavy`, `empty-space`, `edge-crowding` | 경고 | 원본 1.4배 초과, 가중 글자 90 초과, 내용 35% 미만 또는 아래 비어 있음, 글자 가장자리 56px 이내 |
| `text-on-image`, `near-miss`, `no-visual`, `font-fallback` | 경고 | 불투명 그림과 글자 겹침, 형제 정렬 2~10px 차이, 시각 요소 없음, 덱 글꼴에 없는 글자 |

`text-overlap`과 `text-on-image`는 함께 보일 수 있는 것끼리만 판정한다. `data-step`·`data-until`의 구간이 겹치지 않거나 같은 `[data-buddy]` 안의 `data-when`이 겹치지 않으면 제외한다. `empty-space`는 표지·구분·큰 발문과 `data-roomy` 장을 제외한다. 표도 시각 요소다. `selftest`는 고르기·뒤집기·가리개·토글·탭·끌기·답 쓰기·타이머·뽑기·세기·조작을 눌러 보고 끝에 복원한다.

## 7. 부품 (`assets/kit/`)

- `:root`의 `--ink`, `--line`, `--ground`, `--dot`, `--card`, `--coral`, `--yellow`, `--mint`, `--sky`, `--violet`, `--accent`, `--mark`와 `--tone-1`~`--tone-5`를 쓴다. `sunny`·`sky`·`mint`·`grape`는 `palettes.json`과 CSS에서 맞춘다.
- 제목 크기 `--fs-num` 240 · `--fs-ask` 164 · `--fs-hero` 128 · `--fs-title` 100 · `--fs-h3` 60, 본문 크기 `--fs-big` 68 · `--fs-lead` 54 · `--fs-body` 46 · `--fs-small` 38 · `--fs-note` 32 · `--fs-tag` 42 · `--fs-fig` 40px. 각각 제목·본문 배율을 곱한다.
- `.fit`의 컨테이너 폭과 제목의 `--n`을 `cqw`로 계산해 맞춘다. 기본 `.hd h2`는 62px, 수식이 든 제목은 42px 아래로 줄이지 않고 줄바꿈한다(기본 배율 기준). 마스코트 칸 기본은 `--buddy-w:430px`. 학생이 읽는 글자(문장, 그래프의 눈금·축 이름 포함)는 32px 이상, 쪽 번호·저작 표시 같은 보조 글자는 26px 이상으로 두고, `small-text`가 잡지 못하는 26~32px의 학생용 글자는 따로 확인한다.
- 이미지 `img.asset`은 칸에서 `object-fit:contain`. 마스코트의 `data-mood`·`data-when`·`.when-yes/no`와 위젯의 `is-*` 상태에 모양을 준다.
- 단계 표시는 찍히고 제목·내용은 올라오며 마스코트는 뛰어든다. 단계 공개는 기본 `rise`, SVG·수식 안은 `fade`, SVG 선은 `draw`를 쓸 수 있다. 세부는 `kit.css`의 움직임 절.
- 수식은 `overflow-wrap:normal; white-space:nowrap`으로 보호한다. 새 CSS는 평평하게 쓰고 장의 위치·크기·배율을 덮지 않는다.

## 8. 도구 (`scripts/deck.py`)

아래는 명령 형식이다. `deck.py`는 스킬 폴더의 `scripts/deck.py` 경로로 바꾸고, 공백이 있는 경로는 따옴표로 감싼다.

```text
python deck.py new <덱폴더> --title "…" [--kind lesson|training|talk] [--palette 이름]
python deck.py layouts [키,…] [--kit 폴더] [--json]
python deck.py plan <덱폴더> [--kit 폴더]
python deck.py scaffold <덱폴더> [--only id,…] [--force] [--kit 폴더]
python deck.py art <덱폴더> mascot|mockups|assets|all [--only id,…] [--force] [--jobs 4] [--dry-run] [--mode polish|compose]
python deck.py art <덱폴더> import <id|mockup:장id> <그림파일>
python deck.py build <덱폴더|원고.html> [-o 결과.html] [--force] [--student] [--no-font]
python deck.py check <덱폴더|결과.html> [--out 폴더] [--shots] [--slides 2,5]
python deck.py compare <덱폴더> [--slides 2,5]
python deck.py status <덱폴더> [--json]
python deck.py unpack <결과.html> -o <폴더>
```

종료 코드는 0 통과·1 고칠 것 있음·2 도구 실패. `scaffold`는 빠진 장만 끼우고 `진행안.md`도 쓴다. `build`는 없는 `img.asset`을 `data-placeholder`가 든 자리표시로 바꾸며, Pillow가 있으면 `그림/`의 PNG를 긴 변 1200px 이하 WebP로 시험 변환해 더 작을 때 넣는다.

메이플스토리 Bold·Light는 이용 조건의 수정·편집 금지를 지키려고 TTF를 수정 없이 통째로 넣고 `NOTICE.txt`를 주석과 저작권 메타에 남긴다. `fontTools`와 Noto Sans KR이 있으면 원고·엔진의 사용 글자 가운데 메이플스토리에서 빠진 글자만 `Deck Sans`로 보충한다. `--no-font`는 둘 다 생략한다.

`check`는 모든 단계의 `sheet-NN.png`, `--shots`일 때 `slide-NN.png`, 상호작용 장의 `state-NN.png`, `report.json`을 쓴다. `--slides` 부분 검사는 `part-NN.png`를 따로 쓴다. 캡처 전 `<html data-deck-shot>`을 붙이고 효과를 끝낸다. `--shots` 유무와 관계없이 이동 막대·쪽 번호·편집 도구·판서 단추는 캡처에서 숨긴다. 외부 요청은 오프라인 에뮬레이션으로 막는다. `setBlockedURLs`는 SVG data URL 안의 `http://`까지 막으므로 쓰지 않는다.

임페커블이 있으면 `detect`를 실행한다. 지적 원문을 공용 CSS·스크립트·틀에서 생성된 마크업과 작성자가 더한 CSS·스크립트·마크업에 대조한다. 공용에만 있으면 숨기고, 둘 다에 있거나 출처를 가를 수 없으면 `imp-<규칙>`으로 보여 준다. `report.json`의 `imp_hidden`에 숨긴 전체 건수(`total`)와 규칙별 건수(`by_rule`)를 남긴다. 임페커블이 없으면 설치하지 않고 자체 검사만 한다.

`compare`는 시안과 모든 단계를 공개한 구현을 나란히 찍고 `compare.json`과 `대조.md` 틀을 만든다. 임페커블의 `comp-diff`가 있으면 `overall`·`verdict`·`scores`, 없으면 Pillow로 64×36 명도 차와 가장자리 상관을 합친 자체 점수를 쓴다(Pillow도 없으면 점수 없음). 점수는 볼 순서일 뿐 눈으로 대조해야 한다. `status`의 대조 ✓는 `대조.md`가 최신 `compare.json`보다, `compare.json`은 최신 빌드보다 새로워야 한다. 마감 ✓는 최신 검사·대조를 통과하고 `마감.md`가 `report.json`과 `대조.md`보다 새로워야 한다. 시안·에셋의 최신성이나 대조 판정의 실제 내용은 보증하지 않으므로 직접 확인한다.

## 9. 시험

스킬 폴더에서 실행한다. 부품 점검용 임시 견본에는 `scaffold`로 만든 `원고.html`과 `그림/`이 있어야 한다. 점검 도구는 `DESIGN.md`·`PRODUCT.md`를 갖춘 덱을 네 색 묶음과 밝게·어둡게 모드로 검사한다. `--out`에는 임시 점검 기록 경로를 지정한다. `assets/kit/imp-baseline.json`은 유지보수 전후 비교용 과거 기록이며 `check`는 읽지 않는다.

```text
python -X utf8 -m unittest discover -s tests/tools -p "test_*.py"
node tests/engine/e2e.mjs
python -X utf8 tests/kit/stress.py --out "<임시폴더>"
python -X utf8 tests/tools/make_imp_baseline.py --sample "<임시견본>" --work "<임시폴더>" --out "<임시폴더>/imp-audit.json"
```

실제 Chrome이 필요하다. 화면 캡처·크롬 프로필은 지정한 스크래치에 둔다. 운영체제 저장 대화상자, 실제 IME 조합, 글꼴 권한 승인, 실물 터치는 자동 시험만으로 보증하지 않는다.

## 10. 브라우저

Chrome·Edge 기준이다. 컨테이너 단위, `tan(atan2())`, `:has()`, `color-mix`, MathML, `inert`를 쓴다. Firefox·Safari와 실물 터치는 별도 확인이 필요하다. Cambria Math는 Windows 수식 글꼴이다.
